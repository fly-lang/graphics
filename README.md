# Graphics for Fly Language Programming

Here you can find the logo sources for FlyLang, in `logo/`:

| File | Description |
|------|-------------|
| `fly-logo.svg` | Vector master of the logo |
| `fly_logo.png` | 1100×1100, transparent background |
| `fly_logo_300.png`, `fly_logo_500.png` | 300×300 and 500×500, transparent background |
| `fly_logo_circle.png` | 1100×1100, logo on a white disc |
| `square/` | Square variants (1024, 512, 256 transparent; 512 on white) |
| `fly_logo.ai`, `fly_logo.psd` | Editable Illustrator / Photoshop sources |

Artwork is released under [CC0 1.0 Universal](LICENSE).
